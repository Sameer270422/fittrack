# FitTrack — 8 Week Fitness Tracker

A private, browser-based fitness tracker for an 8-week vegetarian fat-loss and muscle-preservation plan.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser.
3. Your data is stored in browser localStorage.

## Main targets
- Calories: ~1,800/day
- Protein: 140–160 g/day
- Goal: ~82–83 kg
- Training: 6-day split with badminton twice weekly

## Notes
Nutrition values are starting estimates. Edit `js/app.js` to match the exact labels/brands you use.

For private use, keep the repository private if you later upload it to GitHub. Do not put real passwords, API keys, or sensitive credentials into the HTML/JavaScript.
